## Work so far

A short summary of what I've done up to now. Some of it may be a little dated,
so the site is the better place for the current picture.

- **Interactive medical image segmentation.** A human-in-the-loop method where a
  clinician makes a few quick corrections and the model adapts as it goes, so
  far fewer slices have to be traced by hand. It was presented at ICVGIP 2024,
  where it received the Best Paper Runner-Up award.
- **Ayu, brain age from neuroimaging.** An attention-based deep network on
  resting-state fMRI that estimates a person's age and highlights which brain
  connections change as we get older. Published in Frontiers in Computational
  Neuroscience, 2022.
- **Covid-19 cough detector.** A CNN on cough audio features (MFCC and Chroma),
  trained on the Coswara dataset and wrapped in a small web app.
- **Earlier work.** Image and video dehazing (ICVGIP 2018, Neurocomputing 2020)
  and host prediction for coronaviruses (Heliyon, 2023).

Papers, project write-ups and figures are on the [site](https://lashuk1729.github.io).
